# Mobile-Sales-Performance-Dashboard
Interactive Power BI dashboard analyzing mobile sales, brands, customer ratings, monthly trends, and payment methods.
Dashboard Preview

"Mobile Sales Performance Dashboard" (Screenshot%202026-11-01%20122443.png)
Key Features

- Total Sales, Units Sold, Transactions, and Average Selling Price KPIs
- Monthly sales trend analysis
- Top 10 cities by sales
- Brand-wise sales comparison
- Customer ratings analysis
- Payment method analysis
- Interactive Brand and Year filters

Tools Used

- Microsoft Power BI Desktop
- Data visualization and analysis
